AI 上市、研究与开发

Anthropic 登陆纳斯达克，首日收涨约 17%

Anthropic 于 11 月 18 日将 A 类普通股定价为每股 83 美元，次日以代码 ANT 在纳斯达克全球精选市场挂牌。公司公告列出的 9.8 亿股中，约 9.56 亿股由公司出售，其余由原股东出售，后者的售股所得不归公司。按发行价算，整笔发行金额约 813 亿美元，未扣费用，超过此前 SpaceX 的纪录。公开报道显示，股票以 111.50 美元开盘，收于 97.17 美元，较发行价上涨约 17%；按充分摊薄股本估算，收盘市值约 1.8 万亿美元。联合创始人 Dario 和 Daniela Amodei 参加了开市仪式。

1500 多条 HN 评论里，一项争议是该用什么股本估值：有读者指出，若按纳斯达克所用的已发行股本计算，同一股价对应的市值约为 1.3 万亿美元。把行情比作 1999 年或 2007 年的人，担心早期投资人借散户接盘退出；另有评论引用招股书，指出部分董事、高管和员工首日最多可出售持股的 10%，创始人须等更久才能较大规模减持。也有读者讨论版权和解金额相对募资规模有多大，以及 Claude Code 如何改变公司在市场上的位置。

工程师称 Claude 找到了安全疏漏，随后拒绝协助评估风险

爱沙尼亚工程师 techtipsy 请 Claude Code 检查自己正在开发的产品。模型先指出一处能用一行代码修复的疏漏，却在他继续评估风险时拒绝协助；换旧版 Claude 也没解决问题。他说，申请豁免要等多个工作日，可能涉及放弃数据保留例外，并提交身份证件。作者称后来完成了验证和修复，也介绍了自己使用的欧盟托管开源权重模型 GLM 5.3。他认为，模型实验室有更强的安全测试能力，却没给普通开发者提供同样好用的防御手段。

HN 评论里，不少开发者分享了修理环境或排查问题时被模型拒绝的经历，担心这种限制也抬高了正当防御的成本。评论里也提到 Kimi、GLM、Mistral 和 Sakana 等模型选项。一些人批评平台将安全能力与额外审批、付费捆绑；也有评论把问题反过来看：软件开发越依赖第三方模型，开发者就越难掌控自己的工具和流程。

Anthropic 称 Claude Fable 5.2 解出了两个黑洞物理问题

Anthropic 11 月 17 日发布两篇预印本，称大部分推导由 Claude Fable 5.2 自主完成。第一项接续约 2003 年列下但未算完的工作，从全息对偶的量子一侧考察霍金和 Page 在 1983 年描述的相变：理论系统升温后从粒子气体转向形成黑洞，即便时空几何不再确定，转变仍是突发的，而非平滑过渡。第二项用自举法在一个较简单的三维引力模型中推得质量界限，以排除不一致的候选理论；最简版本仍不能把界限压到黑洞出现的质量阈值 c/12。两项结果都针对理论模型，尚无直接的现实应用。

Simon Willison 觉得，解出两个黑洞物理开放问题，足以成为前沿模型发布的一项成果；也有读者认可论文是在做理论物理，不只是解数学题。评论同时提醒，研究对象并不直接对应真实宇宙；第二项工作没用这套自举法排除该理论，也不等于证明理论自洽。论文几乎只见 Claude 和 Anthropic 署名，这又引起了对人类作者角色和发表规范的争论。

通讯、服务器与存储

欧盟委员会为逾 4 万名员工部署 Matrix

据会议报道及转载，欧盟委员会 2025 年夏开始接触 Matrix，12 月完成概念验证，2026 年 1 月至 6 月搭好生产环境，7 月至 9 月分批把客户端装到员工笔记本上，覆盖逾 4 万人。委员会自己设计和运营 Element Server Suite Pro，采用经主权托管招标选定的云服务，并接入员工平时使用的 EU Login。Matrix 目前与 Microsoft Teams 并行，对外联邦互通和手机端仍在评估。扩容过程中，员工一度无法跨 Synapse 服务器搜索同事，实时在线状态也因拖慢系统而停用。

评论关心数字主权要以多少成本换来。用过 Matrix 的读者提到验证设备和会话的麻烦，不看好四万人同时上线的体验；质疑者认为 Element 并不是唯一的安全选项。支持者则分享了自建 Matrix、用 Element X 代替 WhatsApp 或 Telegram 的经历，理由是位置共享等数据仍握在手里。在线状态被关掉也引起分歧：有读者把它视为即时通讯的基本功能，有人因此想起早期的 AIM 和 ICQ。

Ruby2Shell 影响默认配置的 Rails，Ruby 已发布修复版

Veria Labs 披露，CVE-2026-132825 是 Ruby 的内存安全漏洞，默认配置的 Rails 和经典风格的 Sinatra 应用可能面临未经认证的远程代码执行风险。问题涉及部分单字节编码的大小写转换，UTF-8 路径不受影响。已知受影响版本包括 4.0.0–4.0.9、3.4.0–3.4.12、3.3.0–3.3.13，并追溯至 2.4.0；修复版为 4.0.10、3.4.13 和 3.3.14。披露时，Mastodon、OpenProject 和 Discourse 已有补丁，GitLab、GitHub Enterprise Server 和 Chatwoot 尚无修复版。

HN 读者指出，这与当日另一则 Ruby 安全公告说的是同一处漏洞。讨论涉及大小写转换中对字符串长度的假设、其他框架的 C 扩展是否也可能出现内存安全问题，以及各自使用的软件何时能更新。

一台 10 GB、单 CPU 的虚拟机跑出千万级 Web 服务

开发者 kapteko 想在 10 GB 内存、1 个 CPU 的虚拟机上跑 1500 万个 Web 服务。他先用 C 写了只做监听、接收、读写和关闭的极简服务，发现内核端口范围和每个 socket 三千多字节的开销，让内存在约 250 万个服务时就用光。换成可不做堆分配的 Rust 协议栈 smoltcp 后，他再比较两种把报文交给用户态的方案：DPDK 直通网卡，AF_XDP 则由内核保留设备，用 eBPF 把报文送入用户态缓冲区。自定义运行时拦截应用的系统调用，接到用户态协议栈。按他的测试，空闲服务约占 620 字节，活动连接约 1 KB，服务数可达 1600 万；DPDK 最快，AF_XDP 紧随其后。

不少读者喜欢这篇文章用一个带玩笑的目标，把系统调用、网络栈和硬件开销串了起来。恰好在探索笔记本千万级连接的人对结果感兴趣，也有读者说标题里的 Web 一度让他误以为主角是 HTTP 解析，险些跳过文章。

DriveVault 预计 SSD 到 2027 年下半年才可能降价

DriveVault 根据 NAND 合约价和希捷、西部数据的投资者材料判断，SSD 价格可能要到 2027 年下半年才缓和，机械硬盘可能更晚，要等到 2028 年。ComputerBase 跟踪的一批常见型号中，2026 年 9 月机械硬盘均价同比涨 134%，SSD 涨 129%，两者都创新高，但环比涨幅已收窄。TrendForce 预计 NAND 短缺将在 2027 年下半年结束；希捷的大部分数据中心产能已经订到 2028 年，数据中心约占其出货容量九成，希捷和西部数据都没有新建工厂的计划。作者建议按实际需要买，不必囤货，并认为短期内很难回到 2024 年的价格。

HN 读者最不认同的是成本下降就会带动零售价回落：成本可以降，终端价格未必跟着降。有人后悔没早点给游戏主机扩容，有人干脆不再升级；也有评论把存储、内存和 GPU 放在一起看，认为只有内存供应也缓和，模型推理成本才可能明显降低。

医学、离线工具与能源

胰腺癌早期试验报告三名患者病情稳定

明尼苏达大学 Masonic 癌症中心的 Masato Yamamoto 团队在美国基因与细胞治疗学会年会上报告，一项针对无法手术、尚未远处转移的胰腺癌的 I 期试验，最低剂量组的三名患者在随访中未见肿瘤继续增大或扩散；研究者称三人均仍在世、病情临床稳定，其中一人的疾病控制据称已达 15 个月，首位患者治疗前肿瘤约 7 厘米。试验登记号 NCT06693986，主要评估一种溶瘤病毒疗法的安全性和剂量，没有对照组，团队计划继续试验。悉尼医生 Kai Brown 提醒，肿瘤学中曾有不少 I 期信号未能在 III 期重现。

评论首先追问三名患者是不是全部受试者、有无对照。回复推测这是首批接受试验治疗的三人，也讨论了晚期试验设置安慰剂组的伦理难题。查阅过试验登记和综述的读者说，溶瘤腺病毒研究已持续多年，进展往往很慢。家属的亲历叙述也让讨论回到临床稳定和治愈之间的区别。

Lastbook 把应急指南、地图和视频放进离线资料库

Lastbook 是一款开源电脑应用。用户联网下载应用和资料库，之后不用联网即可读指南、查地图、看视频，也可安装额外约 17 GB 的本地 Gemma 模型，让它按馆藏回答并给出出处。资料库分三档，约 7.7 GB 至 388 GB，收录急救、饮水、食物保存、维修、电力与应急准备等内容；项目称地图可查 25.8 万多个地点，视频有两千多部。医学资料来自世卫组织、红十字会和 Hesperian 等已出版指南，项目本身未作临床审校。应用支持 Windows、Linux 及搭载 Apple Silicon、运行 macOS 14 或更新版本的 Mac，不支持手机和平板。

HN 讨论集中在没电时该怎么访问资料。太阳能电池板和旧笔记本被视为可能的组合，但若要省电，有读者宁可用 Kiwix 查离线百科，或者直接抄到纸上，不跑本地模型。也有评论联想到 Open Source Ecology 等面向社区重建的项目，提到其中一些已近停摆。

国际能源署：按「有用能」计，建筑制冷需求首次超过取暖

国际能源署在 11 月 19 日发布的《世界能源展望 2026》中指出，以完成降温或取暖服务的「有用能」衡量，建筑制冷需求正首次超过取暖；直接计算燃料和电力消耗，取暖仍较多。中国以外的新兴和发展中经济体中，85% 的家庭每年至少一段时间身处高温，不到五分之一有空调。全球约八成人口生活在至少部分时间需要降温的地方，家庭空调普及率约四成。国际能源署将需求增长归因于收入上升和气温升高。按该机构主要情景，建筑制冷用电将从约 3000 太瓦时增至 2035 年的 4700 太瓦时，增量约 1700 太瓦时，大致相当于目前整个印度的用电；届时制冷或占全球用电约 12%，却占峰值负荷约 30%。

读者首先纠正了把「有用能」读成「能耗」的说法：空调和热泵搬移的热量可以大于设备所用的电。讨论也涉及生活经验和市政方案，既有人提到英国一次热浪就暴露出缺乏降温设备的问题，也有人建议用能兼顾冷热的热泵、改善管道，参考中东的区域供冷，或像北欧一些市政项目那样用数据中心废热供暖。

广告平台与商家

一篇文章把效果广告比成返还率接近 98% 的老虎机

Global Commerce Graph 的文章把谷歌、Meta 等平台的效果广告比作返还率设在 92% 到 98% 的老虎机：报表总像差一点就能打平，让创业者愿意再改一次文案、再投一周。作者认为，广告拍卖会把商家之间的出价推高到毛利所剩无几；早期便宜的广告库存能带来数倍回报，但商家涌入后便难以为继。企业可能耗完种子资金或信贷，一停投流量就消失，也没有积累直接的客户关系。作者建议把精力转向行业关系与转介，文末也介绍了自己面向百人以下公司的商业关系图产品。

HN 评论区争论这个比喻是否成立：赌博是零和，广告并不必然如此；反方说，广告主竞价会让平台拿走大部分额外收益。支持拍卖解释的人觉得这不必归咎于阴谋，也有读者提到平台曾因隐蔽保留价受罚。另一组评论怀念电视广告时代凭创意获得超额回报的机会，认为算法如今会给表现好的广告加价，直到优势所剩无几。线下和传统媒介是否还能提供不同的回报，也被带进了讨论。
