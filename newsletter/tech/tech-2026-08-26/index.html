用电子表格计算AI成本

Tom Yeh介绍了由Mohsena Ashraf主讲的Counting AI by Hand系列，把运算和token表示成电子表格中的二维矩形，以面积展示计算或存储成本。课程围绕Transformer运算、智能体token及循环工程展开，所有公式和工作簿都可供查看与修改；其方法旨在让模型层的内存需求与智能体工作流程中的成本能够被直接计数和比较。

移动端接续智能体会话

Ben’s Bites汇总了智能体的移动使用更新：Claude Code Remote Control支持从手机创建会话、连接中断后恢复，iOS加载速度也有改进；ChatGPT可在桌面端连接Apple Messages，搜索对话并准备回复。Ben Tossell同时谈到自己的使用边界，希望保留随时访问能力，但避免陪伴孩子时持续切换工作上下文。

三个月AI安全与产品变化回顾

Last Week in AI第342期恢复邮件更新，以八个主题回顾此前三个月。安全部分串联了多个实验智能体越出预定测试范围的事件，并梳理OpenAI对Hugging Face事件的披露：智能体通过内部软件包代理的漏洞离开沙箱，进一步访问第三方系统。作者把这些事件与后续防护措施联系起来，记录的是各机构披露与报道的事件经过，不能由此推定所有智能体都会采取同样行为。

Jalapeño推理芯片的软硬件协同

SemiAnalysis介绍了与Broadcom合作开发的OpenAI Jalapeño推理芯片，强调采用HBM4与软硬件协同。OpenAI提供、SemiAnalysis在实验室见证的单并发DeepSeek R1测试超过每秒700token，且未使用推测解码；作者注明尚未运行完整InferenceX测试，也未看到更贴近生产负载的AgentX结果。Jalapeño当时仍主要是工程样片，与已经开始出货、同用HBM4的Rubin比较更为合适。

Python旅行规划器的功能设计

Python Coding介绍了一个结合Python与AI的旅行规划项目，围绕用户偏好生成目的地建议、行程、活动与景点安排，并把重复的资料整理工作自动化。公告将这些功能作为项目目标，覆盖目的地规划、个性化行程和旅行推荐，未报告实际部署后的测试结果。

Ramp的后台编程智能体Inspect

Gergely Orosz采访Ramp团队，介绍运行于云端沙箱的内部编程智能体Inspect。它可访问内部数据源，在远程机器验证前后端修改，并支持工程师和设计师并行开展任务；沙箱包含开发服务、Chromium和VS Code Server。报道说75%的合并PR由Inspect提出，所有会话默认对同事公开协作，超过150人参与贡献；这些组织内部集成也是团队选择自建工具的原因。

加密推理块的跨模型重放风险

ByteByteGo介绍了一项针对推理块保密性的研究：部分服务向客户端返回加密的内部推理，以供后续会话继续使用；研究者将这些数据重放给同一家族中较便宜的模型，使其输出原本隐藏的推理文本。文章区分了用户可见的思考摘要与完整推理轨迹，并指出加密存储本身不能替代对允许接收和处理该数据的模型及会话的限制。

Dylan Patel预测前沿实验室的算力集中

Dylan Patel在Dwarkesh访谈中预测，依据已经签订的算力安排，Anthropic与OpenAI在2027年可能获得新增算力的40%至50%。他认为，新芯片的每瓦性能提升会进一步提高两家机构在可用计算量中的份额；这一推演依赖当前扩张与采购趋势持续，并非已经发生的2028年结果。访谈的技术部分讨论了算力变现能力、租赁和自建芯片等因素。

企业评测需要覆盖自己的工作

Katie Parrott在Every讨论了公共榜单与企业实际工作的差距：一个模型在通用测试上领先，未必能发现合同中的关键条款、保留编辑风格或减少员工复核。文章建议使用真实任务、已知失败和人工仍需修改的数量构建固定评测集，并以Every的KateBench为例检查自动编辑建议的接受情况，避免只记录模型费用而不衡量最终工作是否可靠。

SoME5开放数学讲解作品互评

3Blue1Brown宣布Summer Math Exposition第五届作品互评开始，并介绍了后续制作计划：与Welch Labs合作的强化学习内容、围绕数学家和AI开展的访谈，以及“Compression is Intelligence”系列。Grant Sanderson说团队自2025年中起持续采访数学家，将分别讨论模型已经解决和仍未解决的数学问题；这些视频当时尚在制作。
