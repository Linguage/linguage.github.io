AI 工作方式

怎样让 AI 写出自己的文风

Every 评测负责人 Mike Taylor 回顾了他尝试六年、终于让 AI 写出自己文风的方法。他发现，只让模型读旧作再写一份风格说明，往往会做成夸张的模仿，有时甚至还不如不用这份说明。真正有效的做法是：先把文章抽成不含文风的内容提纲，再用一个「裁判模型」对照原文评判两份草稿，只保留能提高相似度的修改。按这种方法为 Claude Opus 5.5 优化后，草稿接近原文的比例从 16% 升到 93%，他写一篇文章的时间也从一天缩短到大约一小时。不过他强调，技能不能替你决定该说什么，只能把已经想清楚的内容，用你习惯的方式写出来。

代码变便宜之后的软件工程

微软 CEO 萨提亚·纳德拉接受 The Pragmatic Engineer 采访，讨论当写代码变得便宜、校验对错反而更难时，软件工程会变成什么样。他认为许多团队除了换一个新工具，还要在日常工作之外搭建「软件工厂」，把说明、生成、校验和线上反馈连成闭环。他承认 GitHub Copilot 一度落后，是因为 Claude Code 在大约六个月内让命令行取代了传统编辑器，说明模型能力一跃升，使用形态也会跟着变。他还主张企业把模型、记忆和操作框架拆开，避免被单一供应商锁住，并把智能体当作「内部风险」来校验；初级招聘放缓，在他看来是团队仍在摸索新工作方式，属于阶段性调整。

Software engineering after code becomes cheap with Satya Nadella · The Pragmatic Engineer

Jev 创作者谈 AI 自动化的可靠性

Harry Stebbings 对话 TypeSafe AI 联合创始人、Jev 创作者 Diogo Almeida，从可靠性切入 AI 自动化的落地难题。节目介绍，Jev 在让软件自动作出判断的同时，也向开发者反馈每次判断的置信程度。讨论随后转向数据质量与算力扩张的关系、每个 token 带来的智能增量，以及基准测试能否反映真实能力。

两人还追问：应用公司如何应对基础模型厂商复制，开放模型的能力差距会怎样变化，以及持续增长的 GPU 需求是否足以支撑当前投资预期。节目时长约 1 小时 14 分。

安全与评估

网络安全里的 1990 年代正在回来

a16z 的网络安全文章认为，2026 年攻防两边的节奏，正越来越像 1990 年代末到本世纪初：严重漏洞不再隔几年才出现一次，而开始变成安全团队的日常。作者把转折点放在 Claude Opus 4.5/4.6 一类模型出现之后——发现漏洞和编写利用代码变得更快、更便宜，连多年反复审计过的基础软件也再次出现问题。他们预测，自行传播的网络蠕虫可能回潮，企业也将被迫更快打补丁，因为「先别自动更新、免得把系统弄坏」的旧逻辑，已经赶不上进攻的速度。文中给安全负责人的建议是：把渗透测试做成持续、不限范围的红队演练，并围绕检测与响应的速度重建防御，避免只堆叠一层层未必都在运转的防护设备。

OpenAI 启动第一阶段嵌入式评估

OpenAI 宣布与 Apollo Research、METR、Transluce 和 Goodfire 签约，开展第一阶段「嵌入式评估」：让独立评估者在较长时间内深入接触内部模型与系统，检验对齐情况和安全机制是否有效。按评估需要，对方可以获得模型检查点、源代码、训练与评估数据、监控系统和技术文档，并与相关研究者交流。Apollo 将重点看模型是否会隐蔽地违背开发者意图，以及现有机制能否发现这类行为；Goodfire 做可解释性与训练过程监控；METR 计划评估其迄今最大规模强化学习训练中的失准行为；Transluce 则先审查训练后对齐评测的质量与覆盖面。Greg Brockman 随后转发了这份公告。

独立创始人如何应对 token 欺诈

ChatPRD 独立创始人 Claire Vo 回顾了过去一年因 token 欺诈损失数万美元的经历：有人批量领取免费试用、转售促销码，把产品包装成转发服务，甚至用自定义 MCP 将其变成全天运行的算力工人。她按六类滥用模式介绍商业与技术防线，包括用 Jev 实时识别异常，最后决定取消免费试用。

她强调，AI SaaS 卖出的不仅是软件功能，也是持续产生成本的计算资源，连 AI 客服也可能成为滥用入口。

视觉智能

用图像、运动和声音一起训练视觉智能

Latent Space 采访了黑森林实验室的安德里亚斯·布拉特曼和达斯汀·波德尔，讨论他们为何把图像生成模型 FLUX 3 同时用在图像、视频和声音上。布拉特曼用接球作比：人不必写出球的轨迹公式，手就会提前伸出去；一张静帧只能告诉你球在哪里，视频能告诉你它怎么过来，撞击声则能补上镜头没拍到的接触时刻。这就是他们所说的「视觉智能」：模型要从运动和声音里学到关于三维世界的线索，而不仅仅是把单帧做漂亮。他们也谈到，把每一帧单独锐化，画面可能都很好看，连起来却会闪烁，所以视频超分辨率必须和同一套骨干模型一起考虑时间一致性。一个他们没预见到的用途是：人们用 FLUX 修复褪色的家庭老照片，再拿给亲人看——这提醒他们，身份能否在修改和连续帧里保持稳定，最终是被人仔细端详的。

李飞飞随 World Labs 加入 AMD

AMD 于 11 月 16 日宣布完成对 World Labs 的收购，把这家做交互式三维环境与机器人仿真模型的团队并入公司，希望同时推进计算平台和模型。李飞飞出任执行副总裁兼首席科学家，直接向 CEO 苏姿丰汇报。官方新闻稿强调，World Labs 将继续做基础模型研究，并与 AMD 工程师一起，把对新能力的理解用到面向开放生态的下一代 AI 基础设施上。Yahoo Finance 报道，这是一笔约 82 亿美元的全股票交易。苏姿丰与李飞飞随后都在 X 上确认了这次会合。

研究与日常创造

OpenAI 扩大科研人员免费使用计划

OpenAI 宣布，将把 ChatGPT for Academic Researchers 计划扩大到全球最多 20 万名科研人员。下一轮于 11 月 23 日开放申请，向符合资格的申请者按先到先得方式发放 5 万份资助，每份覆盖申请者和最多两名合作者，提供免费的 ChatGPT Plus。此前试点使用 Pro，公司根据使用记录判断，大多数参与者的需求在 Plus 限额内，因此调整方案以覆盖更多研究团队。

这项计划于 7 月开始试点，已有 33 个国家的 2 万名科研人员加入。研究用途包括连接实验室与患者数据、寻找结核病药物靶点，以及把博物馆标本照片整理为可检索数据库。公司称，默认不会把该项目中分享的数据用于训练模型，并继续提供培训和支持。

Paul Stamets 谈蘑菇研究

Andrew Huberman 与真菌学家 Paul Stamets 从菌丝体的生物学谈起，讨论蘑菇在免疫研究、认知与环境修复中的应用。节目涉及云芝、Agarikon 等真菌的抗病毒与免疫研究，也探讨猴头菇、虫草和灵芝相关话题。

后半段聚焦裸盖菇素用于抑郁等问题的研究、微剂量使用，以及法律、安全和专业支持的重要性。官网列出了对应论文，包含细胞实验、早期临床试验及观察性研究；这些不同层级的证据不能直接等同于普遍疗效或自行使用建议。

Kevin Kelly：我的速写本

凯文·凯利在 The Technium 写了新文章《My Sketchbook》。他给「艺术」下的工作定义是「酷而无用的东西」，并介绍了自己今年的每日约定：用一本 5.5×8 英寸的速写本，记下当天发生的事，或由这些事触发的想法。他通常在晚上花 20 到 30 分钟完成一页，媒介包括钢笔、水彩和丙烯彩笔。文章附上了若干样张，并说视觉日记比文字日记更能一下子唤起那天的感觉，希望能鼓励还在犹豫的人养成这个习惯。
