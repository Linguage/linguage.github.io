科技剪报 · 2026-11-05｜PE 承压、AI 决策陷阱与数字童年

整理：henri

本期围绕 AI 研究与工程、产业与商业、人机协作与健康、数字文化与信息表达展开，关注编码工具整合、模型更新、安全研究和可证明推理，讨论并购基金、AI 建造史及行业人事；通过专家使用 AI 的决策研究、癌症护理经验、家庭电脑房和对数轴等材料，观察技术如何进入工作、照护与日常理解。

AI 研究与工程

OpenAI 拟收购 Pierre 补齐 Codex 的 Git 工具链

OpenAI 宣布拟收购 Pierre Computer Company，补强 Codex 中浏览文件、审阅变更与保存代码历史的工具。Codex 现已使用 Pierre 的 Trees 与 Diffs 库，后者可让审阅者直接在差异视图中修改代码；Pierre 的其他产品还包括实时语法高亮工具 Highlights，以及基于 Git 保存代码和历史的 Code Storage。OpenAI 计划把这些能力逐步带入 Codex，并承诺开源项目继续开源、Code Storage 客户在收购完成后仍可使用服务。交易尚待惯常交割条件和监管批准，交割前双方仍独立运营。同日关于 Conductor 并入 Meta/MSL、HumanLayer 并入 Factory 并计划开源的消息，也把注意力引向编码 Agent 周边工具的整合。

Cognition SWE-2 Flash：更快更便宜的编码模型

Cognition 发布 SWE-2 Flash，以 Thinking Machines 的 Inkling-Small 为基础，采用 276B 总参数、12B 激活参数的架构，并在强化学习前加入中期训练。官方称，相比 SWE-2，它的速度约为三倍、价格约为五分之一，面向自动化、代码审查、功能开发和文档更新等日常工程任务。训练后的 Terminal-Bench 4.0 得分由基础模型的 0.9% 升至 20.0%，FrontierCode 2.0 从 3.2% 升至 24.0%，但不同基准表现仍有差异。模型已进入 Devin Desktop 和 CLI，Pro/Max/Teams 用户可免费试用至 11 月 30 日；因网络安全能力可能被滥用，权重暂不公开，团队计划向可信行业伙伴与研究机构提供受控访问。

cognition.comSWE-2 Flash↗

Images 2.6：更快生成与 GIF 动画

OpenAI 推出 Images 2.6，在 ChatGPT、Codex 和 API 中增加更快的图像生成与 GIF 动画能力，并强调多轮编辑时人物、产品和品牌细节的一致性。官方称生成速度较此前提高 50%；API 提供 Flare 与 Sunburst 两个选择，前者在低画质设置下最快约六秒出图，后者偏向需要更高细节和编辑一致性的任务。开发者还可用图像标注指定修改位置、导出 SVG，并通过新增的 complexity 参数控制场景规划投入。复杂度与画质是不同控制项：简单修改可降低复杂度以缩短等待，多元素或多约束场景则可增加规划投入，避免把所有任务都按同一种高成本方式处理。

Anthropic FlashProve 与 vault 粒子结构

Anthropic 的 FlashProve 尝试回答一个服务信任问题：用户收到的回答，是否真的由服务商承诺的模型生成？系统用 zkSNARK 提供可验证的推理证明，隐藏模型权重，但不以隐藏架构为目标。在四位量化、整数预填充等条件下，官方报告单张 H100 可为 Llama 4 Maverick 以约每秒 110 token 生成证明；不过 GPU 成本仍约为直接推理的 70–95 倍，属于研究进展而非低开销的即用方案。另一项生物学研究中，Claude 在研究人员指导下参与序列检索、纯化方法优化和显微数据处理，帮助解析由噬菌体蛋白形成的 vault 结构，纯化由通常约三天缩短至约 90 分钟。研究揭示了结构与组装方式，vault 的生物功能仍未确定。

自主流水线寻找 Linux 本地提权漏洞与补丁

OpenAI 公开一套在受控环境中运行的 Linux 漏洞研究流水线：从候选问题发现、动态复现、可利用性验证到生成候选补丁，最后由人工研究员审查并向维护者报告。一次运行分析了 2,308 个候选问题，复现 1,724 个漏洞，产出 948 个可工作的本地提权利用，API 费用约 120 万美元。这里的数量代表研究与验证结果，不等于 948 项修复已经合入上游；补丁仍需维护者审核，后续报告与修复通过 Patch the Planet 协调。同日 Daybreak Red 将 GPT-5.6 Cyber 带到 AWS GovCloud，通过 Bedrock 向符合资格的团队提供授权安全研究能力，访问仍需 OpenAI 审批及 AWS 配置。

Latent Space：AIEi 上海幕后

Latent Space 的约 72 分钟幕后对谈由 Galen Gao 访问 swyx，借 AI Engineer Shanghai 回顾一个开源 AI 博客如何发展为播客与工程师社区。节目讨论公开学习、写作与创始人故事，也借 Kill My SaaS 比赛追问：Agent 即使能重建工具并通过入场检查，是否就满足组织者真正要完成的工作？这种区分把评估从功能演示推进到产品判断。同组推荐中，Warp 创始人 Zach Lloyd 则把「软件工厂」描述为可写入代码、可运行和可衡量的系统：明确仓库、技能、MCP 与工作流，让需求分流、规格编写和实施进入可重复的工程过程。

产业与商业

私募股权还撑得住吗？

a16z 用房地产比喻拆解科技并购基金的处境：这类基金以借债收购成熟企业为主，依赖技术趋于成熟、商业模式可预测后产生的稳定现金流；作者认为新一波 AI 更利好风险投资。文中对比近十年美国并购基金年化回报约 14.5%、低于 Russell 3000，而风险投资整体约 17.6% 且无杠杆；在 2007–2016 年成立的基金中，表现前 5% 的美国风投基金，其已分配现金与实缴资本之比（DPI）约为 5.3 倍，并购基金则为 3.5 倍。2021–2022 年的高价收购叠加利率上升后，部分企业把无力支付的利息计入贷款本金（PIK），债务相对资产价值的比例随之上升；基金也更多地把企业卖给自己管理的新延续基金，以延长持有期。作者认为，2010 年代持续降息、可通过经营改善提高价值的收购标的，以及基金之间不断加价转手的条件，难以靠几次降息重现，并提醒基金出资人核查利息计入本金的规模与退出路径。

约 150 人如何建造现代 AI：Kevin Roose 谈《The AGI Chronicles》

Every Podcast 访谈科技记者 Kevin Roose。他为新书采访约 150 人，追溯 OpenAI、Anthropic、DeepMind 等实验室中受保密协议限制、外界难以了解的决策史，包括 Altman 被罢免与复职等幕后。播客摘要提到他用 NotebookLM 整理资料，并用多个 Claude 智能体组成的审稿小组（分别扮演怀疑论者、历史研究者和写作编辑）交叉审稿，曾抓出人类编辑漏掉的事实错误。Roose 认为风险真实但结局未定，「当下选择会决定未来几年到几十年」；他离开《纽约时报》后与 Casey Newton 创办面向公众的 AI 媒体。

Cat Wu 离开 Anthropic

据 Business Insider，Claude Code 产品负责人 Cat Wu 已于 10 月 30 日离开 Anthropic，公司确认了这一消息。她在 11 月 3 日发文感谢团队与用户，但没有公开说明离职原因。Wu 于 2024 年加入公司，参与 Claude Code 早期产品开发，与原始创建者 Boris Cherny 一起推动工具面向用户，也负责非编程工作产品 Cowork。此次离职发生在公司筹备上市期间，此前同属 Claude Code 团队的 Thariq Shihipar 也宣布离开；报道没有据此认定产品方向发生变化。

人机协作与健康

当 AI 的意见由抛硬币决定

Slow AI 介绍 Anthropic 10 月 27 日研究：61 名具备因果推断背景的专业分析师在 Claude Code 中做统计任务，其中 50 人使用给定 Agent；这 50 人中约 65% 拥有硕博或六年以上经验，90% 自评熟练或专家。研究者用抛硬币的方式随机决定 Agent 的意见，结果专家约 86% 的决策跟随了该意见。作者借此讨论「AI 诱导失能」：人在使用 AI 时，可能把原本由自己作出的判断交给系统。

theslowai.substack.comAnthropic Rigged 50 Experts' AI With a Coin Flip↗

用 ChatGPT 帮母亲抗癌的五步工作流

Peter Yang 把癌症护理写成可复用的产品经理流程：用开源 /fuck-cancer skill 生成一页简报（患者信息、下一步行动、已知事实、术语白话、护理日志），尽早索取书面病历、影像 DICOM 与病理蜡块，并借助美国国家综合癌症网络（NCCN）指南了解标准治疗、寻求第二诊疗意见，研究肿瘤测序与临床试验选项，同时定期向外部专家发送病情更新。他强调美国约五分之二的人一生会面对癌症，诊断常拖延数月；在他的照护经历中，AI 尤其有助于跟进跨科室文书与随访。文中同时提醒保护与家人相处的时间，避免把护理完全变成任务清单。

creatoreconomy.soHow I’m Using ChatGPT to Help My Mom Fight Cancer↗

数字文化与信息表达

电脑房里的受监督上网

Abha Ahad 在 Default Friend 发表的系列《The Machine in the Girl》首篇聚焦她定义的“千禧一代与 Z 世代之间的女性”（1992–2001 年出生）：她们多半通过共用家庭台式机认识网络，知道「关机走开」是什么感觉，却在成年后几乎活在设备里。作者以印度家庭电脑房、新泽西地毯店后室与俄亥俄客厅 iMac 等访谈说明：硬件摆在客厅带来「父母看得见就安全」的错觉，而孩子学会把屏幕转开、迅速关闭浏览器标签页，让同人小说看起来像学习材料。文章把硬件物质文化放回互联网史叙事中心，提醒算法成瘾之外，成长时期如何接触网络，同样塑造了人们保护隐私和展示自己的习惯。

default.blogThe Supervised Internet of the Computer Room↗

何时该用对数轴

《经济学人》Off the Charts 回应读者对其性犯罪定罪率图表使用对数轴的批评：线性轴强调绝对差，对数轴强调倍率与变化率。文中用苹果股价在不同 CEO 时期、马斯克薪酬相对其他 CEO 的倍数，以及新冠早期各国病例轨迹说明——当关心「翻倍还是腰斩」或极端离群值挤占版面时，对数轴能让趋势可读。作者承认对数轴初看反直觉，但若目的是呈现比率而非原始差额，它能揭示线性轴上难以辨认的趋势。

theeconomistoffthecharts.substack.comAt loggerheads: When to use a log scale↗

日谈公园 · 半拿铁

日谈公园以努力、运气和时代为线索，讨论一代人的三十年。《半拿铁·商业沉浮录》的《莆田鞋往事》则把视角落到一座制造城市：潇磊与刘飞从 1958 年的国营鞋厂讲起，梳理代工积累、仿冒鞋兴起、安福销售网络以及球鞋鉴定与造假之间的较量。约 126 分钟的节目随后转向自主品牌与「莆田鞋」集体商标，讨论擅长制造为什么不自然等于能够建立品牌，最后延伸到产业现状与产能转移。
