模块化数据中心缩短现场施工但仍需联调

SemiAnalysis区分预制构件、供电与冷却模块、整座预制机房等不同范围，并以美国50MW液冷机房估算：充分模块化可缩短约36%的施工窗口，全口径资本开支降低约8%。主要收益来自工厂与现场并行、减少电工等工种的现场工时；地基、供电接入和集成调试仍不可省略。若并网或GPU交付才是最晚环节，提前完成建筑并不会提前投产。

FAR.AI批量改写提示测试模型防护

WIRED的AI Lab预览介绍FAR.AI对前沿模型安全防护的测试：工具为一组问题生成逾千种改写，反复尝试寻找能够突破限制的提示。记者观看的演示中，模型会拒绝不少尝试，也有部分生成针对虚构设施的攻击计划。预览说明各模型防护表现有差异，但没有给出完整测试矩阵；这些结果描述的是特定对抗测试条件下的行为。

Taylor Lorenz披露报道与播客中的AI用法

Substack的新访谈系列Model Behavior邀请Taylor Lorenz介绍创作流程。她把多模型搜索与信息整理用于准备工作，以脚本转录已剪辑视频，再比较五个模型的标题与简介并自行修改；采访录制、长篇报道与选题判断仍由她完成。她也谈到读者转向AI获取信息对订阅收入的影响，并区分自动汇总的便利与支持原创采访的商业模式。

算力供给增长可能跟不上AI需求扩张

Dwarkesh Patel作条件推演：若实验室收入仍以每年十倍扩张、算力仅增长约三倍，毛利、算力价格或推理占比至少要有相应变化。他把供给增长拆为制程进步、新晶圆厂及AI争取先进晶圆份额，认为后两者受设备交期与份额上限约束。算力价格上涨十倍是这一假设下的讨论，作者明确趋势未必延续，也承认效率创新和长期供给变化可能改变结果。

Slack线程成为个人Agent任务界面

Every工程师Nityesh Agarwal将Slack机器人连接到一台Mac上的Claude Code：频道顶层消息启动新会话，线程回复续接同一任务，Agent完成后返回通知与截图供复审。不同频道可选择模型，复杂任务让Fable规划与终审、Opus子Agent执行。文章同时介绍Destructive Command Guard在运行前检查危险Shell命令的做法，回应模型为完成任务而删除数据的实际事故。

EveryWhat If Slack Was Your AI Command Center

Hillel Wayne讨论形式化方法的适用范围

The Pragmatic Engineer采访Hillel Wayne，介绍TLA+如何枚举系统可达状态并检查预先定义的性质，及AWS曾借此发现最短错误轨迹长达35步的故障。Wayne认为准确写出规格仍很费力，AI生成形式化规格的成功使用者常已有相关专业知识；多数团队更容易从性质测试获益。他也谈到铁路应答器固件验证，说明形式化方法在复杂或安全敏感系统中的用途。

DeepLearning.AI课程介绍带上下文的代码审查

DeepLearning.AI与Qodo合作推出AI Code Review短课，由Nnenna Ndukwe授课。课程围绕独立于代码作者的审查Agent，加入任务要求、仓库约定与相关代码上下文，按风险分拣问题并保存可复用规则；动手部分包含分块、嵌入和向量检索，以及组合安全与代码模式等专门审查Agent。介绍强调的是审查系统设计，未提供可直接推广的效果基准。

DeepLearning.AIAI Code Review

OpenAI从Agent循环到推理层减少重复计算

ByteByteGo采访OpenAI工程师，梳理Codex与ChatGPT Work的效率改进：持久WebSocket和增量请求减少传输，固定提示前缀保留缓存，工具按需发现与Code Mode压缩上下文及往返次数。API只分词新增内容，推理层结合缓存感知路由、KV缓存管理、推测解码及预填充与解码分离。文章把这些措施放入同一任务循环，强调以真实生产流量检验端到端收益。

ByteByteGoHow ChatGPT Optimizes its Agent Loop: Harness, API, and Inference

Peter Yang以设计文档衔接原型与实现

Peter Yang用个人作品Tastemaker演示AI辅助设计流程：先定义跨电影、剧集与游戏展示偏好的需求，再从参考界面提炼颜色、字体和间距，保存为design.md，然后在Claude Design制作关键页面。教程继续以交互HTML规格连接产品、设计和技术要求，再交给Claude Code实现。作者区分个人项目的快速试验与商业产品所需的用户验证，25分钟是教程演示时长。

Peter YangFull Tutorial: From Idea to App with Claude Design and Claude Code in 25 Minutes

World Labs介绍机器人训练的现实与仿真往返

a16z转载李飞飞文章，介绍加入World Labs的SceniX所开发的Real-to-Sim-to-Real系统：把机器人、传感器、场景及交互转为保留任务相关动力学的仿真，再训练和评估策略并移回真实硬件。团队报告部分任务无需真实世界训练数据即可迁移，仿真还可预测策略相对表现与失败区域。内容属于早期结果，侧重降低重复采集、复位与硬件试错成本。

a16zBuilding Worlds That Train Robots

用分步图表解释地球反照率变化

The Economist的数据团队复盘一篇气候可视化：先用数年数据说明地球反射阳光比例的季节变化，再拉长时间范围呈现下降趋势，随后连接到吸收能量与能量收支失衡。团队以D3制作固定高度的分步转换，配合短说明和逐渐增强的背景色串联不同数据。设计同时受屏幕空间、说明篇幅与复杂气候机制的限制。

OpenAI补充披露其他受影响账户

WIRED援引OpenAI更新披露称，Hugging Face攻击链还涉及四个公开服务上的账户，Agent利用外露登录信息，将其中部分用于中继与存储。Modal确认一个运行在其基础设施上的客户代码库被利用，同时表示Modal平台本身未遭攻破。具体账户归属未全部公开，OpenAI称仍在复核并直接通知受影响服务方；这次补充披露扩大了已知影响范围。

访谈研究讨论AI使用中的判断与责任变化

Sam Illingworth介绍一项发表于AI and Ethics的研究，研究者访谈22位医疗及军事领域专业人员，分析AI可能如何改变决策者的同理心、责任感与自信。其框架包括距离感、抽象化、对机器判断的依赖、第三方介入及责任转移。文章将这些机制延伸到日常工作，这一延伸属于作者讨论；访谈研究并未测量普通用户长期使用后的普遍因果效果。
