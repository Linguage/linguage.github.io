模型研究与风险

笔记本上的 Qwen 3.8 27B 也能「读」网络权重

Simon Willison 复现论文 Sparks of Weight-Space Programming：前沿模型可在无工具情况下，从原始浮点权重判断简化网格游戏策略网络在玩什么，甚至直接改权重。他用本机 Qwen 3.8 27B（约 17GB）跑通 Breakout、Pong、Pac-Man 等提示，耗时约 46 分钟到 1 小时、数万推理 token，多数猜对；更冷门的 Freeway 失败。作者把「只看权重理解行为」与「带代码去改模型」拆开讨论，认为前者更有意思，并提醒别据此宣称「源代码时代结束」。同信还更新美国普查局 AI 采纳问卷：问题从「生产商品/服务」扩到「任何业务功能」，不同时间的结果需谨慎比较。

simonw.substack.comQwen 3.8 27B on my laptop can interpret model weights, too

如何逃出 AI 自动驾驶

Every 重发 Katie Parrott 的文章：作者曾因把大量工作交给 AI 而将同一客户稿件完整重做一遍，事后才发现自己几乎没有记住完成过这件事。文章借用驾驶舱自动化研究与「易读即更真」的加工流畅性实验，说明系统越流利可靠，人类越容易把「看起来像审过」当成真审过。她提出的对策是：在模型给出答案前先形成自己的判断、核对主张与假设，并亲自确定写作意图、作出价值判断。这些做法对写作、策略与传播类工作尤其相关，并不要求减少 AI 的使用。

every.toHow I Escaped AI Autopilot

黄仁勋看好开源与闭源模型

黄仁勋在 Fireworks Forge 与创始人 Lin Qiao 对谈时表示，闭源前沿模型仍有明确位置，但企业不必把所有任务都交给通用模型。他更看重专业领域的智能：在开放权重的前沿模型上加入行业知识、专用工具和合适的评估，可以形成适合特定业务的系统。The Register 指出，这种路线与 Fireworks 的模型定制服务一致，而无论客户选择开放还是闭源模型，Nvidia 都能提供底层硬件。谈到下一阶段，他将今年的进展归于把模型变成 Agent 的运行框架，并预期安全部署 Agent 的 Open Shell 和硬件在环的机器人系统会成为新的重点；这些是他的行业判断，而非已经兑现的技术结果。

www.theregister.com黄仁勋看好开源与闭源模型 · The Register

Anthropic S-1 警告接近 RSI 能力阈值

Anthropic 在 11 月 2 日修订的 S-1/A 中说明，公司越来越依赖 AI 设计、训练、测试和优化后续模型，这可能让研发速度超过安全措施的验证与落实速度。文件称，部分衡量依据是滞后指标，过去也曾在加速已经发生后才识别出来；根据内部估计及对未来模型的预期，公司可能很快达到其负责任扩展政策中「由 AI 带来的显著加速」阈值。这一判断针对未来模型，目前没有模型被认定越过该阈值，相关数据仍在评估。递归自我改进由此成为研发管理与风险披露中的具体问题，但这份文件并没有宣告 AI 已能脱离人的监督，自主开发下一代前沿模型。

AI Daily Brief：AI 朝向递归自我改进

NLW 在约 27 分钟的节目中，把递归自我改进放进一个更实际的问题里：模型能力加速，是否就会带来更快的商业采用？他从 Grokbot 的使用额度与服务成本争议谈起，再讨论大模型直接修改较小模型权重的研究，以及 Anthropic 招股书对 AI 加速研发的表述。对权重编辑实验，节目同时保留了热情与限制：它展示了新能力，但部分显著提升来自修复推理循环，受试模型的规模也不能直接类比前沿系统。NLW 最后强调，企业惯性、既有流程和落地难度仍会影响使用量，更强模型与更多收入之间未必存在简单的直线关系。

工程与开发工具

软件工程的两个时代：每月合并 PR 从 8–20 个增至 200 多个

Pragmatic Engineer 征文冠军 Neil Kakkar 用自己在 Bloomberg、PostHog 与 AI 原生创业公司 Tano 的数据对比：在 AI 原生团队，他每月合并 PR 约 200+，较 PostHog 时代提升约 11 倍。旧瓶颈如沟通开销与强制人工 code review 被削弱——一人端到端交付、CI 里的审查 Agent 成默认；新瓶颈变成频繁切换并行任务、共享上下文流失、项目知识过度集中于个人，以及自我节奏管理。文章的价值在于用可核对的个人产量数据，说明 AI 提速如何让工程师面对新的约束，避免把产量增长写成口号式生产力神话。

newsletter.pragmaticengineer.comHow software engineering is changing: a tale of two eras

生产级 Agent 的执行边界

Architect’s Notebook 把 Agent 定义为「模型参与决定下一步」的系统，核心机制是工具调用环：模型生成结构化请求，应用校验并执行，结果再喂回模型。文章强调把概率性模型放进确定性外壳——工具白名单、参数与业务规则校验、步骤/token/成本预算、高影响动作的人审、可观测与可逆设计；并区分固定流程图的 workflow 与动态决策的 agent。关键提醒：关键业务规则必须写在代码里，不能只写在 prompt 中；不要仅为追求新奇而默认采用 Agent。

thearchitectsnotebook.substack.comBuilding AI Agents: From Tool Calling to Production Architecture

用户反映 Codex 训练开关重新开启

一名 Hacker News 用户称，自己与同事为避免公司代码等知识产权通过提示词外流，曾主动关闭 Codex 的数据共享，但后来发现「Improve the model for everyone」开关重新开启，且没人记得再次同意。帖子引来超过四百点赞和关于训练同意的讨论，并指向 ChatGPT 的 Data controls 与 OpenAI 隐私门户，供用户检查自己的设置。这里反映的是用户对设置变化的报告：关闭开关能否持续生效、不同入口的设置是否一致，以及发生变化时是否有清楚提示，是争议的具体焦点；帖子本身没有说明变化的技术原因，也不能据此断定所有账户都受影响。

news.ycombinator.comHN 讨论

Pando：为 Agent 单体仓库扩容的 Git 后端

OpenAI 为不断扩大的单体仓库重建了 Git 后端 Pando。Codex 让工程师同时推进更多分支，每次提交又会触发多项 CI 任务，读写请求随之放大；新系统保留 Git 协议和客户端兼容性，不要求团队改变既有命令与工作方式。它按分支分别协调更新，使互不相关的推送可以并行，同时复用压缩对象包，让多个客户端从缓存读取相同数据，减少逐请求计算。代价是同时观察多个分支时，可能看到不同时间点的状态。官方称生产环境中的推送延迟中位数降至原来的约五分之一，每天提供接近 1PB 的 Git 数据。

产业与消费

SpaceX 冲击 13GW：可能成为世界上最快的 AI 云建造者

SemiAnalysis 跟进 SpaceX/xAI 数据中心扩张：此前「2027 年 10GW」遭广泛质疑，如今约 3.6GW 已在多地开建，目标上修至约 13GW——大致相当于把 Google 近三十年累计机房容量压进一年半。作者称已找到可承载超过 9GW 容量的站点，并称建设速度可能超过多数中国同业；Colossus 2、Starbase 改造、疑似 TeraFab 旁侧机房，以及美国大规模电池储能系统（BESS，近 6GWh）与移动燃气轮机「边建边定电」是关键拼图。文中强调 Tesla 模块化机电供应、最短约 4 个月的新建数据中心工期，以及自备供电与申请接入电网并行的做法，认为工业执行力本身正成为 AI 云的护城河。

newsletter.semianalysis.comElon Is Doing It Again: SpaceX Will Be The World’s Biggest AI Cloud

长寿经济的状态：价值迁向「行动层」

a16z 结合约 500 名美国消费者调研与行业观察：疫情与 ChatGPT 把主动健康管理推入主流。文章梳理个人健康管理入口的争夺、标榜「无毒」产品的消费需求（如 63% 听说过微塑料、62% 愿为标有 non-toxic 的产品支付更高价格）、肽类热潮与胆固醇/Lp(a) 进入日常对话，以及可穿戴设备进入第三阶段：从计步转向监测更具体的生物标志物。对创业者的核心判断是：AI 让解释变便宜后，更高的付费意愿会流向能安排检查、预约、随访与处方的服务，单纯的问答框难以获得同样的溢价。

www.a16z.newsThe State of Longevity

Jill Hazelbaker 出任首席企业事务官

OpenAI 宣布 Jill Hazelbaker 将出任首席企业事务官，负责全球传播与企业定位，并向总裁 Greg Brockman 汇报。她此前任 Uber 总裁兼首席企业事务官，在公司工作约十年，管理过传播、营销、安全与人事等团队，也曾在 Snap 和 Google 担任传播领域的高管。此次任命着重于公司如何向公众解释 AI、建立品牌与信任；OpenAI 的公告也把这一岗位放在支持全球业务扩张、加强公众沟通的背景下。

罗永浩的十字路口：对话徕芬创始人叶洪新

《罗永浩的十字路口》新一期与徕芬创始人叶洪新对谈，节目约 3 小时 19 分钟，围绕一个通过自学进入硬件行业的创业者展开。官方简介梳理了他从经营女装淘宝店积累资金，到尝试载人飞行器、电动滑板车并接连受挫，再到研发高速无刷马达与吹风机的经历。节目不只回顾成功后的产品，也谈早期现金压力、遭遇骗子、营销选择、研发投入以及创始人的精力分配。其核心线索是产品能力怎样在反复试错中形成，以及从单项技术走向可持续消费电器业务时，研发、成本与市场之间如何取舍。
