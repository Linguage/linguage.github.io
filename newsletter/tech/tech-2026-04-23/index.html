科技剪报 · 2026-04-23

整理：henri

本期关注AI开发工具的质量与使用管理、软件工程实践、网络安全及共享出行。工程师访谈记录Token用量目标诱发的浪费，界面复刻比较呈现作者对设计理解和代码功能的观察，Anthropic调查说明Claude Code质量下降涉及的变更；Lambda递归限制、CSS状态编译和手机靶纸识别案例展示资源控制与软件实现方法。公民实验室研究揭示电信信令接入遭滥用的手机定位活动，XBOW内部评测报告GPT-5.5在其渗透测试工作流中的表现，Voi经营报道则介绍共享短途出行的运营规模与业务方向。

AI开发工具与质量管理

把Token用量设为目标的后果

Gergely Orosz采访Meta、微软和Salesforce工程师，记录用量榜单及最低消费要求怎样诱使员工运行无用任务。他提到Meta一个月消耗60.2万亿Token，但按API标价换算的9亿美元只是等价估算，实际支出未知。作为对照，Shopify改用使用仪表板、检查高额调用的用途，并设置支出突增熔断，试图把实验和浪费区分开。

生成设计图到可用软件之间的差距

Ben’s Bites的Keshav比较从截图制作界面及应用的工具，认为Claude Design更能理解设计意图，但转成可运行应用时仍会出现视觉偏移。他观察Opus 4.7较贴近参考图，GPT-5.4的代码功能和未展示页面的一致性较好，且图片、图标和纹理缺失会拉低复刻效果。通讯同时记录Images 2.0、团队工作区智能体及研究API的发布。

Claude Code质量下降的三项原因

Anthropic公布对Claude回答质量下降反馈的调查，称三项独立变更影响了Claude Code、Claude Agent SDK和Claude Cowork，API及推理层未受影响。第一项是3月4日为降低长延迟，将默认推理强度从high调为medium，用户反馈后于4月7日撤回；第二项是3月26日上线的优化，本应在会话闲置超过一小时后仅清理一次旧推理，却因缺陷在此后每轮持续丢弃历史推理，造成遗忘、重复和异常工具选择，4月10日修复；第三项是4月16日加入的精简回复提示词，与其他提示词变更共同损害编码质量，更广泛的消融评估中有一项显示Opus 4.6和4.7成绩下降3%，4月20日撤回。公司称全部问题已在4月20日的v2.1.116中解决，并于4月23日重置订阅用户额度，后续将增加公共版本内部使用、逐模型评估、持续测试和渐进发布。

软件实现与工程实践

给Lambda递归触发加上限制

Amit Raghuvanshi延续S3与Lambda费用事故，提出分离输入和处理结果的存储桶，或用严格前缀、后缀限制触发范围，避免输出再次触发自身。第二道限制是预留并发额度，控制同时执行的函数数量，为告警和人工处理留时间。作者称在预发布环境测试递归场景时，加入限制后的费用为23美元。

用编译器明确CSS状态优先级

Andrey Yamanov在维护组件系统时发现，悬停、激活、禁用、主题和响应式条件叠加后，样式规则容易相互覆盖，选择器优先级相同时还会依赖源码顺序。他开发的Tasty允许按属性声明状态映射及优先顺序，再由编译器生成带有排除条件的互斥选择器，使同一属性一次只匹配一个分支；扩展组件时，开发者可以合并样式对象，由编译器处理状态关系。作者介绍，项目经过多年迭代，主要难点是让伪类、属性修饰符、媒体查询、容器查询、嵌套选择器和类型化接口共同工作并保留声明的优先级。Tasty已用于拥有100多个组件的Cube UI Kit及Cube Cloud，作者认为它适合长期演进的设计系统，小型落地页使用普通CSS通常更合适。

用手机视觉识别为靶纸计分

Vadim Drobinin为减少射击训练中逐孔使用黄铜量规计分的工作，开发了在iPhone上离线运行的靶纸识别应用。他先尝试Apple Vision及一篇2012年论文中的传统图像处理方法，但环线、印刷数字、纸张撕裂和重叠弹孔使检测不够可靠，随后将两种方法结合：OpenCV负责靶心、环线及透视校正，在自有数据集上微调的YOLOv8负责定位弹孔，再按弹孔位置与环线半径计算分数，模型通过CoreML部署到手机。工程难点还包括Vision与UIKit坐标原点不同，以及可见破口小于实际弹径，需要用人工计分靶纸校准补偿参数。作者将应用命名为Notch，并探索用累计热图和弹着散布反馈训练趋势；正式比赛中，黄铜量规仍承担依规则裁定争议分数的职责。

网络安全与漏洞评测

电信信令接入被用于手机定位

Lorenzo Franceschi-Bicchierai报道，公民实验室识别出两起利用电信基础设施追踪手机位置的活动，未具名的监控供应商通过伪装成合法移动运营商获取网络接入。研究人员发现，两起活动都借用了019Mobile、Tango Networks UK和Airtel Jersey的基础设施作为入口或中转节点；其中一起先尝试利用SS7缺陷，失败后转向Diameter，另一起向一名高知名度目标的SIM卡发送用户不可见的特殊短信，以SIMjacker方式获取位置。报道指出，SS7缺乏认证和加密，较新的Diameter虽加入安全机制，运营商未完整实施保护措施仍会留下攻击空间。研究人员将这两起活动视为更广泛滥用中的有限样本；Airtel Jersey所属的Sure则表示，不会直接或明知故犯地出租信令接入用于追踪，并称已采取监测和封锁措施。

XBOW评测GPT-5.5渗透测试能力

XBOW将提前获得的GPT-5.5接入自身多模型智能体工作流，使用冻结在已知漏洞版本的开源应用，评估从发现到利用漏洞的完整过程。公司报告，在其内部基准中，GPT-5.5的漏洞漏检率为10%，低于GPT-5的40%和Opus 4.6的18%；不提供源码时，GPT-5.5的表现已超过获得源码的GPT-5，加入源码后则进一步提高。交互测试中，GPT-5.5的视觉识别成绩为97.5%，成功登录所需迭代次数约为次优模型的一半，识别无效凭据或访问受阻的耗时也约减半。在应当放弃的示例中，它仍会过度坚持，但发生频率约为此前GPT版本或Opus的一半。这些结果来自XBOW自身的系统和测试集，公司计划继续在生产部署中评估，并按任务保留不同模型。

共享出行运营

Voi的2025年运营规模

Micromobility Pro介绍Voi的2025年经营表现：公司净收入为1.782亿欧元，车队规模扩大34%，骑行次数增长55%至1.16亿次。通讯称其业务覆盖12个国家的130多个城市，运营约16万辆共享滑板车和电助力车。公司把安全、可靠的短途出行作为主要方向，希望减少城市居民对汽车的依赖。
