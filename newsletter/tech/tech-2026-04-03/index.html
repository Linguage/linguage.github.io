科技剪报2026-04-03

科技剪报 · 2026-04-03

整理：henri

本期涵盖支付幂等处理、GitHub平台可靠性、Railway前端迁移和Claude Code发现内核漏洞的案例，以及设计画布与智能体交互实践。围绕人工智能，作者讨论测试与注意力瓶颈、技术承诺与商业叙事，支出数据呈现企业软件与AI预算的分化，认知研究考察人们未经核验接受AI推理的行为。科学内容包括硼基质子交换膜的制氢测试、莫尔晶体模拟高维电子行为的研究，以及追踪阴蒂感觉神经的三维成像预印本研究。

软件系统与安全

支付重试为何需要幂等处理

The Architect’s Notebook以付款成功但响应丢失、用户再次点击的场景说明重复扣款风险，讨论客户端生成幂等键、服务端原子占用键值的处理思路。文章继而介绍支付系统还需处理账本、跨服务事件、补偿和外部对账，把网络超时后的未知状态作为架构设计的重点。作者把重复请求、竞态条件与财务状态核对联系起来，强调失败路径需要提前设计。

GitHub如何承受智能体流量

Gergely Orosz结合第三方状态跟踪与GitHub事故说明，讨论数据库饱和、故障切换后的配置问题，以及编码智能体带来的流量增长。他认为平台可靠性和面向智能体的仓库基础设施需要成为重点，并引用Pierre对高频建库能力的自报数据作对照。文中约90%的可用性来自包含故障和降级的第三方统计，不能理解为所有用户持续无法访问。

The Pragmatic EngineerDoes GitHub still merit “top git platform for AI-native development” status?↗

Railway迁出Next.js

Victor Ramirez介绍了Railway将生产前端从Next.js迁至Vite与TanStack Router的工程实践。其仪表盘和实时画布高度依赖客户端状态，原有Pages Router需要额外封装才能支持共享布局，前端构建也已超过10分钟，其中约6分钟耗在Next.js。团队通过两个拉取请求推进迁移：先用浏览器原生API或框架无关方案替换Next.js专用依赖，再提取页面组件、迁移200多个路由，并引入Nitro集中管理重定向、安全头和缓存规则。新架构为营销等页面保留服务端渲染，其余界面主要由客户端驱动，结合Fastly边缘缓存和带内容哈希的资源分块减少重复下载。据作者报告，迁移实现零停机，构建时间降至两分钟以内；相应代价包括自行替换部分Next.js生态工具，以及承担TanStack Start成熟度较低带来的风险。

Railway BlogMoving Railway's Frontend Off Next.js↗

Claude Code发现长期潜藏的内核漏洞

Michael Lynch报道，Anthropic研究科学家Nicholas Carlini在安全会议上展示了使用Claude Code发现Linux内核漏洞的过程：以简单脚本逐文件引导模型分析源码，减少重复搜索，并将任务描述为安全竞赛中的漏洞查找。其中一个潜藏约23年的NFS漏洞涉及锁请求被拒绝时的响应与重放缓存处理，最长1024字节的锁持有者标识可使响应达到1056字节，超出112字节缓冲区，造成内核内存越界写入。Lynch检索到五项Carlini直接修复或已向维护者报告的Linux漏洞；Carlini另称手中还有数百个未经验证的崩溃案例，人工核验已成为提交报告前的瓶颈。文章据此认为模型的漏洞发现能力正在快速提升。

人工智能与人机协作

Pencil把提示词放上设计画布

Xinran Ma试用Pencil的桌面应用和Cursor扩展，介绍类似Figma的图层、属性与画布，以及智能体通过MCP读取设计上下文的方式。作者认为画布便于追踪方案变体，便签式提示块还能保存生成意图、复制到其他画布复用。他同时提醒，手动修改设计后仍需要求智能体更新代码，当时尚不具备自动双向同步。

Linear如何让智能体的行动可见

Karri Saarinen提出Linear的人机协作设计原则：明确标示智能体身份，让它沿用平台已有操作，收到任务后即时反馈，并展示执行、等待和完成状态。用户应能查看工具使用和决策过程，也能要求智能体立即停止。关于责任，他强调委派者需要事先提供环境、上下文和约束，并承担结果；逐步确认每个动作可能把人变成审批瓶颈。

编码变快后测试成为瓶颈

Simon Willison整理访谈中的判断：编码智能体缩短了原型实现时间，但挑选方案、测试产品和确认软件值得信任仍需投入；多智能体并行还可能迅速耗尽人的注意力。通讯另试用以维多利亚时代书籍预训练的Mr. Chatterbox，指出其对话能力有限，且后续合成对话微调削弱了纯历史语料的说法；最后记录Gemma 4本地运行与多模态能力的初步体验。

研究探讨对AI的认知让渡

Kyle Orland报道了宾夕法尼亚大学研究者对人类使用大语言模型进行推理的研究。研究者在直觉思考与分析思考的既有框架之外，提出由外部算法驱动决策的“人工认知”，并用“认知投降”描述用户很少进行内部思考、未经核验就接受AI推理的行为，强调其与仍保留人工监督的任务委托存在区别。研究通过认知反思测试考察受试者面对AI答案时的判断，发现受试者会接受错误的AI回答；奖励条件能促使他们审查并推翻错误答案，时间压力则会加重依赖。研究者还指出，流畅、自信且容易获取的模型输出可能促成这种未经审查的接受。

材料与能源

硼基膜降低电解制氢能耗

绿色氢能要扩大应用，仍需克服电力成本和电解设备效率的制约。Zach Winn报道，MIT衍生公司1s1 Energy将经过化学改性的硼连接到聚合物上，制成质子交换膜，利用其质子结合与传导特性改善电解效率，并通过材料的抗腐蚀性提升耐久性。公司称，在与合作伙伴开展的测试中，采用其膜的电解槽每生产一公斤氢所需能量为现有设备的70%；联合创始人Dan Sobek另称，潜在客户预计采用该技术可降低约60%的运营成本。公司正在与伙伴开展试点，并合作扩大膜材料生产；燃料电池、固态电池和矿物提取等用途仍在探索或试验中。

莫尔晶体模拟四维电子行为

MIT物理研究团队在发表于Nature的研究中提出化学合成路线，让晶体生长时形成内置莫尔超晶格，制备数以万计的样本，减少过去逐片剥离、堆叠和调整二维材料的手工步骤。团队在强磁场下研究这些晶体的电子与磁学性质，发现相互干涉的两套晶格可用四维“超空间”描述，量子振荡测量显现出额外合成维度的特征；电子仍处于三维物理空间，其部分运动性质在数学上模拟了四维量子材料。自然生长样本表现出较高质量与可重复性，为研究高维导体、超导体及拓扑性质提供了实验平台，但将这些基础研究成果转化为实用技术仍有多项障碍。

生命科学与医学成像

三维成像追踪阴蒂感觉神经

Lauren Schneider报道，阿姆斯特丹大学医学中心研究人员利用同步辐射光源的CT成像，对两名绝经后遗体捐献者的骨盆样本进行微米级三维观察，追踪阴蒂主要感觉神经——阴蒂背神经的走向。既往研究描述这条神经接近阴蒂头时逐渐变细，新图像显示它向阴蒂头伸出丰富分支，并分支通向阴阜和阴蒂包皮。研究人员认为，这些解剖信息有望帮助改进生殖器切割后的重建手术，并减少外阴附近手术中的神经损伤。这项研究于3月20日以预印本发表，尚未经同行评审；团队计划扩大样本数量与年龄范围。
