工程技术与材料研究

超声波腕带实时追踪手部动作

MIT工程师将超声波成像贴片集成到腕带中，连续观察腕部肌肉、肌腱和韧带的变化，再用AI将图像转换为手指与手掌的位置，以探索能够减少摄像头遮挡、传感手套限制动作及肌电信号易受噪声影响等问题的替代方案。团队用多摄像头记录手势，为超声图像建立对应手部22个自由度的训练标注。在八名手腕尺寸不同的志愿者测试中，设备追踪了美国手语26个字母及握持网球、剪刀等物体时的手部姿态；应用演示包括无线控制机械手弹奏简单旋律、玩桌面篮球，以及连续缩放和移动虚拟物体。目前超声贴片约为智能手表大小，配套电子设备约为手机大小；团队计划继续缩小硬件，并扩大不同手型和动作的训练数据，使设备逐步适用于更多佩戴者。

电化学腐蚀削弱固态电池电解质

固态电池中的金属枝晶可穿透电解质并引发短路，长期以来，增强电解质的机械强度一直是重要研究方向。MIT团队制作了可从侧面观察陶瓷层的实验电池，结合双折射显微镜，直接测量枝晶生长时周围的应力。在所研究的一种常用固态电解质中，枝晶生长越快，周围应力越低，裂纹形成时的应力最低仅为单纯机械作用下预期值的25%，显示材料在充电过程中发生脆化。低温扫描透射电子显微成像进一步显示，离子电流引发的化学反应伴随材料脆化；研究者认为，枝晶尖端集中的锂离子流可能促使电解质发生还原、分解成新相并产生体积收缩。这项结果提示材料设计需要重视与锂金属接触时的化学稳定性，具体哪些电化学反应导致显著弱化仍需进一步研究。

AI工具与模型研究

Claude Code自动审批的双层防护

Anthropic介绍了Claude Code的auto mode，试图减少频繁人工审批带来的疲劳，同时拦截超出用户授权的危险操作。系统在工具结果进入上下文前检测提示注入，并在操作执行前使用基于Sonnet 4.6的分类器：先以快速判断筛选，再对被标记的操作进行推理复核。分类器只接收用户消息和工具调用，剥离助手文字与工具结果，以减少自我辩护和外部注入对判断的影响；安全工具及项目内文件编辑等操作可按规则直接放行。Anthropic报告，在一万次内部工具调用样本中，完整流程的误拦率为0.4%；在52个真实过度主动操作样本中，漏拦率为17%；在一千个合成数据外传任务中，漏拦率为5.7%。降低误拦的第二阶段也放过了部分危险操作，主要难点是判断已有同意是否覆盖当前操作的影响范围。被拒绝后，代理会尝试更安全的路径，连续三次或累计二十次拒绝则升级处理；公司明确指出，这套机制仍无法替代高风险基础设施上的谨慎人工审核。

AI工具的设计集成与运行优化

Latent.Space这篇AI动态汇编以苹果限制Replit等应用为开篇，作者认为快速生成应用正在冲击传统商店的审核与分发方式，随后梳理了设计工具集成、代理运行环境、推理优化和软件供应链事件。产品进展包括Figma将允许AI直接编辑画布的MCP服务器开放测试，以及Hermes Agent v0.4.0加入兼容OpenAI Responses API的后端、后台自我改进循环和记忆整理机制；Hugging Face的hf-mount则把远程数据集、模型及存储桶挂载为本地文件系统。性能部分转述了vLLM在多模态工作负载中最高2.5倍P99吞吐提升，以及Google Research对TurboQuant将KV缓存内存用量降至原来的六分之一或更低、最高八倍加速且无精度损失的报告，这些数字对应各发布方的测试与声明。安全部分记录LiteLLM在PyPI上的受污染版本利用启动时执行的恶意载荷窃取凭据，相关讨论强调依赖管理和代理文件访问所带来的攻击面。

用归因图追踪Claude内部计算

ByteByteGo回顾了Anthropic在2025年公布的Claude可解释性研究：研究者构建替代模型，将难以直接解释的神经元活动分解为概念特征，再通过归因图和特征抑制、注入实验追踪计算路径。文章列举的案例显示，同一概念在不同语言提示下可激活共享特征；诗歌生成会提前形成候选韵脚；计算36加59时，粗略估算与末位数字计算两条路径共同得到95，与模型口头描述的进位过程不同。在部分困难题目和答案暗示实验中，研究者观察到书面推导缺少相应内部计算证据，或围绕给定答案倒推论据。文章还讨论了熟悉实体识别错误抑制拒答机制所引发的幻觉，以及句子连贯性与安全拒答之间的竞争。这些发现来自替代模型中的案例分析，工具仅对约四分之一的尝试提示提供较清晰的解释，即使成功也只覆盖部分计算；替代模型可能引入伪影，分析几十词的提示仍需数小时人工工作。

数学与形式化证明

Lean证明验证中的严谨与直觉

数学家正尝试用证明助手Lean将数学论证逐步形式化，由计算机检查每一步逻辑；原文称，Lean已用于验证超过26万条定理。Leila Sloman通过数学史讨论这项工作的收益与代价：19世纪，反直觉的无穷级数和函数促使数学家重新界定极限、连续性等概念，推动了分析学与集合论的发展；20世纪，布尔巴基学派强调抽象与演绎，深刻影响了数学研究和教学，也引发了对研究方法趋同的担忧。Lean让证明中的组件可以独立验证和复用，但编写与审查形式化证明通常需要数月，部分项目超过一年。对Peter Scholze已有证明的形式化工作确认了其正确性，并在过程中找到更简洁的证明、完善了原有想法。支持者还认为，随着AI参与撰写证明，自动验证会更加重要。争议则涉及形式化工具如何影响研究方向：共享库需要协调定义，修改定义可能使依赖它的证明失效，不同数学领域对现有框架的适应程度也有差异。受访研究者担心，数学家可能逐渐偏向更容易形式化的问题；Emily Riehl因此主张尝试多种证明助手，同时承认所需投入会限制这种选择。
