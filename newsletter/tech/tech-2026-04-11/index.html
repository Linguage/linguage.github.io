软件工程

架构拆分带来哪些新负担

ByteByteGo比较单体、微服务和无服务器架构：单体便于小团队部署，微服务提供独立扩容与发布能力，同时增加服务发现、追踪和路由工作；无服务器减少基础设施管理，却需处理冷启动和平台依赖。通讯还比较智能体通过CLI或MCP调用工具的组织方式，介绍AWS常用服务分工与JWT结构，强调实际系统通常组合采用多种模式。

用背压保护视频服务的核心路径

The Architect’s Notebook以YouTube式视频服务说明背压设计：入口先做准入与限流，控制请求和大体量视频数据分别处理，各阶段使用有界队列并向上游反馈负载。上传、转码和播放以异步管道分离，失败时退避重试；极端负载下可延迟上传、降低默认画质或暂停非关键功能。文章用这些架构模式解释如何阻止局部拥堵演变为级联故障。

人工智能

Gary Marcus如何解读Claude Code

Gary Marcus把Claude Code视为神经符号混合路线的实例：语言模型之外，确定性循环、分支判断和代码工具承担执行控制。他据泄露源代码中的核心文件结构，认为提升实用性需要把概率模型与传统程序结合，单纯扩大模型规模不足以解释变化。作者把这一判断联系到自己长期主张，同时承认Claude Code仍会出错，混合架构也只是更可靠系统的起点。

航天探索

阿尔忒弥斯二号完成载人绕月测试

NASA宣布，阿尔忒弥斯二号的四名宇航员乘猎户座飞船于4月10日太平洋夏令时17时07分在圣迭戈附近海域溅落，完成近十天的绕月测试飞行，并打破阿波罗13号于1970年创下的人类离地球最远飞行纪录。此次任务首次搭载宇航员评估猎户座飞船，机组测试了生命支持系统，并通过手动驾驶演示验证操控性能，为后续交会对接操作收集数据；其他测试涉及运动期间的飞船运行、应急设备与程序及生存系统航天服。机组还参与人体组织对微重力和深空辐射反应等研究，并在4月6日飞越月球期间拍摄了逾7000张月表与日食影像，记录晨昏线附近低角度光照下的地形，为未来月面任务的操作和科学观测提供资料。
