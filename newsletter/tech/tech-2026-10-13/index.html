本期收录Claude多智能体编排、语音开发博客、Meta模型发布和AI公司的商业压力，另有创业公司护城河、专科诊所增收及AI术语的讨论。

Agent / 工程

Anthropic Dynamic Workflows：让 Claude 自己编排多 Agent

Anthropic的Dynamic Workflows让Claude先制定计划，再编写程序分配子智能体任务、收集结果和管理信息流。Latent Space记录的股票扫描演示把扫描与复核分开执行；这种方式能发现更多细节，但成本高于单个智能体，开发者仍需设置预算并检查执行过程。

latent.spaceHow Anthropic’s Dynamic Workflows Coordinate Claude Agents (Updated with video!) — Latent Space

用语音让 Codex 给博客加上「新闻通讯」页

Simon Willison记录了自己一边做饭、一边用Codex语音模式给博客增加新闻通讯归档的过程。他口述页面位置、搜索规则和导入需求，由Codex修改Django模型、视图和模板，再通过浏览器检查结果。案例中的关键条件是他事先知道功能应当如何工作。

simonw.substack.comI built a new feature for my blog using my voice

模型 / 产业叙事

前沿实验室的「WeWork 时刻」？

Gary Marcus质疑前沿AI实验室的高估值能否成立。他把开源模型引发的价格竞争、收入预期下调，以及智能体失控可能带来的法律责任放在一起，借WeWork作类比，讨论资本预期与实际业务之间的差距。

garymarcus.substack.comCould this be the Frontier Labs’ WeWork moment?

Meta Muse Wonder模型发布

Latent Space汇总Meta的Muse Wonder和Wonder Full发布消息，介绍两款模型的能力定位、访问方式及个人智能体应用。Wonder通过API和Muse Code提供，Wonder Full面向部分订阅用户；Meta强调跨任务记忆、持续完成任务和专业领域表现。

latent.space[AINews] Meta Muse Wonder & Wonder Full: MSL’s Claude 5.5-tier Frontier Model

商业 / 产品

如何判断创业公司有没有护城河

Lenny Rachitsky与Dan Hockenmaier提出评估创业公司护城河的三步方法：识别能随使用增长的优势、判断其潜力，再看它是否已经产生效果。文章重点讨论切换成本、网络效应、规模经济和数据效应，并区分这些长期优势与执行速度、品牌和分销带来的暂时领先。

lennysnewsletter.comHow to tell if a startup has a moat

专科诊所的约 1080 亿美元 AI 机会

a16z介绍Prosper AI对美国专科诊所的研究，估算AI可通过接听漏接电话、提醒患者复诊、减少保险拒赔和追收患者欠款，提高诊所收入。研究结合约2000家诊所的电话调查等数据，估算潜在增收约为每位医生每年12.5万美元。

a16z.newsThe $108 Billion AI Opportunity for Specialty Practices

AI 术语地图：先画地图再进领地

The Architect’s Notebook区分人工智能、机器学习、深度学习、生成式AI和大语言模型，说明它们对应的任务和系统要求。文章也解释训练与推理、上下文窗口与长期记忆的区别，以及为什么流畅的模型回答仍需要验证。

thearchitectsnotebook.substack.comEp#151: AI in 2026: What Are We Actually Talking About?

产业与商业

AI基础设施借贷与收入之间的距离

Hedgie讨论以债务支持GPU和数据中心扩张的趋势，认为硬件折旧、融资成本与尚未兑现的收入增长之间存在风险。作者把算力视为需要电力、芯片与长期资金的工业项目，同时对工具使用者能否获得相应生产率提升提出疑问。

hedgie.marketsThe GPU Debt Trap

产品与工作流

Meta Muse如何设计长期对话体验

How I AI访谈Meta设计总监Alex Cornell，讨论用渐进呈现降低个人Agent的使用门槛，维持持续对话关系，并在生成界面时保持操作的一致性。节目也展示作者整理收藏、分析棋局和转换旧博客内容的使用案例。
