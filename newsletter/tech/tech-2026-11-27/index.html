模型评测与研发

SemiAnalysis：Astra 在 GDPx 上领先，Neon 赢在使用口碑

SemiAnalysis 用 GDPx 测试模型在芯片设计、材料和软件工程等领域解决难题的能力。这套题特意挑了研究团队认为模型可能带来高价值的工作，不是按各行业占 GDP 的比重抽样。11 月初，Claude Opus 5.5 以 12% 的得分领先；这轮更新后，GPT-6.2 Astra 以 19.3% 居首，Claude Fable 5.2 得 16.4%，Gemini 4 Carbon 和 Neon 则在 10% 左右。

总分掩盖了模型的分工。Astra 在材料科学和硬件设计等研究题上较强，也是这套评测里首个在法律题上得分超过零的模型。软件工程一项则由 Fable 5.2 以 24.4% 领先，Astra 大致只有它的一半；Fable 平均每题约花 88 美元，并输出约 123 万个 token。SemiAnalysis 的作者认为，Neon 在网上更受欢迎，反映的是人们也看重交互是否顺手，而榜单衡量的是另一类能力。

阿莫迪区分两件事：让 AI 做具体工作，和让 AI 决定规则

Anthropic 首席执行官达里奥·阿莫迪在 X 上回应外界对公司立场的批评。他说，把治理权交给 AI 是个坏主意，不能为了效率或安全放弃人的自主决定权。他把这与自动化具体工作分开：模型可以承担驾驶或从头到尾编写软件等任务，但谁来决定目标、在多大范围内使用模型，仍是另一个问题。

争论在模型参与研发时变得具体。Anthropic 的上市文件称，每一代 Claude 都在帮助开发下一代；阿莫迪也表示，公司不认为让 Claude 在缺少实质性人工监督和理解的情况下，独立开发一代又一代前沿模型是安全的。他提出，可以考虑给递归自我改进设限，也就是限制模型在多大程度上能继续改进模型本身。他没有在这次回应中给出具体上限。

企业工具与智能体

Clay 不想让自家的智能体成为唯一入口

获客工具公司 Clay 的 AI 负责人 Jeff Barg 在 Latent Space 访谈中说，客户可以用 Clay 自己的智能体，也可以在 Claude Code 等外部工具里调用 Clay；公司希望两种用法的效果接近，而不是把更好用的功能留给自己的界面。他说，两种用法目前已接近各占一半。Clay 在 9 月融资 1.15 亿美元，估值 71 亿美元。

Barg 粗算，把数据库里约 4000 万家公司按某个理想客户标准过一遍，大概只要 1500 美元。这是一次初筛的估算；遇到需要查多份材料、再决定下一步动作的工作，Clay 才会把更强的模型用在调研和编排上。客户不愿每次手选模型，公司准备按任务自动分配；底层调度则用消息队列自建。Barg 说，智能体现在仍很难从长串运行记录里指出具体哪一步出了错。

Cognition 的 Devin 开始由告警和定时任务触发

Cognition 联合创始人 Scott Wu 在访谈中说，一些新工程师入职后直接用 Devin 接手代码任务，不再先把仓库拉到自己的电脑上。他估计，公司内部约 90% 的 Devin 使用由某种自动化流程触发，而非工程师逐次发出请求。比如线上出了错，系统可以先启动 Devin 查日志、整理可能的原因，值班工程师接到告警时，已经有初步线索可看。这个比例说的是任务从哪里启动，不是说九成代码由 Devin 写成。

Wu 还说，过去约一年里，Cognition 的工程团队人数大致翻倍，合并的 PR 数约增为原来的 20 倍，按人头算约 10 倍。合并数是他用来对照团队产出变化的内部指标。这组数字没有单独度量改动的大小、复杂程度或交付质量。

OpenAI 小范围测试保密推理，保护模型处理中的内容

萨姆·奥特曼说，OpenAI 已开始让少量客户测试 Private Inference。按公司的产品说明，这项能力把保密计算与访问控制结合起来，保护模型正在处理的提示词和回复。零数据保留（ZDR）回答的是处理完之后由谁保留内容：符合条件的 API 工作流中，OpenAI 不在处理后留下客户的提示词或模型回复。两项功能管的是不同阶段。

OpenAI 还把一项已有能力放在同一套企业隐私方案里：在 ZDR 下，客户可把符合条件的加密记录留在自己控制的存储中，由隔离环境做自动安全检查。按公司说明，OpenAI 员工看不到底层内容，系统只返回有限的风险信号。Private Inference 目前仍是 API 预览的小范围测试，奥特曼没有公布收费或全面开放的时间。

公司与市场

标普把英伟达的 AA 评级列入负面观察

标普全球评级把英伟达的 AA 发行人评级和优先无担保债务评级列入负面观察。英伟达的评级仍是 AA；标普这次改变的是观察状态。路透社和彭博报道，标普把管理层和董事会如何应对近期变动列为关注点，尤其关心公司对黄仁勋的依赖，以及董事会能否在支持管理层的同时开展独立监督。

按报道引述的评级说明，标普约有 90 天来观察这些问题。如果风险持续，评级可能下调一档至 AA-；只有公司声誉或业务前景受到更明显损害时，才可能下调更多。穆迪在同期维持英伟达的 Aa1 评级和稳定展望，认为黄仁勋回来减少了近期的不确定性。这次两家的评估落在不同问题上：标普强调董事会能否约束长期风险，穆迪的表态则着眼于复职对近期经营的影响。
